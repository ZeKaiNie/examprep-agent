# P3c Web 界面：需求

目标：本机浏览器里完成“导入资料 → 学一章 → 点引用看原文”的完整流程，后端是 P3b 的 `examprep serve`。界面中文。

## R1 课程

1. 首页列出已导入的课程（名称、语言、资料目录、更新时间），点进去开始学。
2. 导入：输入本机资料目录（可选课程名），实时显示每个文件的进度和最后的导入报告（章节、题数、提醒）；完成后课程出现在列表里。
3. 顶部显示是否已配置模型；没配置时学习按钮给出配置说明。

## R2 学习对话

1. 打开课程即打开学习会话；刷新页面后从对话记录恢复之前的对话。
2. 讲解流式显示；完成后换成系统渲染好的版本（引用可点）；逐句核对完成后再换成核对后的版本，并显示核对结果（几句有依据、几句标了 🟡）。
3. 🟡 开头的段落（资料以外的补充）显示得更轻，一眼能和资料内容区分开。
4. 题目卡片（题干、选项、出处、题图）、判分卡片（判定、理由、参考答案及出处）、提示、拒答、压缩结果、章节完成都有各自的样式。
5. 下一步建议显示成可点的按钮；输入框回车发送；处理中禁用发送，可以点“停止”。
6. “压缩上下文”按钮；显示上下文已用多少、多少时自动压缩。

## R3 原文阅读器

1. 点讲解里的引用（“第1章_线性表.md p.1”），右侧打开阅读器，跳到那一页，高亮被引用的证据块，并滚动到高亮处。
2. PDF 可以切换“页面图像 / 文字”；可以翻页。
3. 出处不可点或页面不存在时给出提示，不白屏。

## R4 进度

左侧显示章节列表：状态（未开始/学习中/已讲完/已验证）、段数、题目对了几道，当前章高亮；待回炉错题数；突击/长期模式和距离考试天数。

## R5 工程

1. `web/`：Vite + React + TypeScript（strict）；开发时 Vite 把 `/api` 代理到 `127.0.0.1:8765`。
2. `npm run build` 输出到 `packages/app/src/examprep/web/`，`examprep serve` 直接提供；构建产物不入库。
3. 测试：SSE 解析（任意切块）、引用链接、事件归并（流式→最终→核对、对话记录恢复）、页面高亮切分、主要组件渲染；`tsc` 零错误。
4. CI 增加 web 任务（类型检查、测试、构建），加入 main 分支保护的必过检查。
