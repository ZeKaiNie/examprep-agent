# examprep

ExamPrep Agent 的应用层（L3）：资料引擎、知识库、学习者模型、教学 Agent、服务与 CLI。

当前（P2）已实现资料引擎：

- 读取 PDF / DOCX / PPTX / Markdown / TXT / HTML，按页保留文本，去掉页眉页脚
- 文件分类（课件 / 笔记 / 作业 / 试卷 / 答案）、章节划分、题目抽取与答案配对
- PDF 图区检测与裁剪、扫描页识别、题目区域裁图
- 课件注入检测与材料围栏
- 600 字证据块切分与 BM25 检索
- SQLite 落库（课程、文件、页、章节、证据、图、题目、任务），按文件哈希增量导入，进程池并行解析
- 命令行：`examprep ingest <资料目录>`
