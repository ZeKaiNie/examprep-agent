# P2 资料引擎：需求

范围：新包 `examprep`（L3）中的资料引擎 `examprep.ingest`、证据检索 `examprep.knowledge`、存储 `examprep.store`，以及最小命令行 `examprep ingest`。
不含 LLM 任务（知识点抽取等放在 P4）和 Web 服务（导入进度 SSE 接口随 P3 的服务一起做）。
依据：`docs/design/01-skill-analysis.md` 第 5 节复用清单、`docs/design/03-architecture.md` 第 4、5.1 节、`docs/design/06-roadmap.md` P2 行。

## R1 移植 Skill 的规则引擎
1. 文本工具：清洗、分词（英文单词 + 中文二元组）、分段打包、中文数字。
2. 读取：PDF（pypdfium2）、DOCX、PPTX（含备注）、Markdown/TXT（utf-8-sig / gb18030 / latin-1，`\f` 分页）、HTML；页文本少于 20 字记为空页；页眉页脚去除。
3. 文件分类：solution > exam > homework > notes > lecture，先看路径再看正文开头；跳过隐藏文件、README 等、超过 200 MB 的文件。
4. 章节：文件名编号、文件内递增章标题拆分、无编号文件顺排；图片文件按编号挂到章。
5. 题目：四种题号风格、节标题重置编号、教材题号精确配对、`pair_key` 配对解答文件、扫描页不续接、题型识别、分值、章节归属（显式 → 教材题号 → BM25 推测并标记）。
6. 规则判分 `grade_answer`：选项、对错、数值（容差）、短填空；文字填空只判“对”或“不确定”。
7. 图：PDF 图区检测（嵌套 Form XObject 坐标变换、聚类、过滤小框与装饰框、每页最多 4 张）、扫描页识别、渲染裁剪为 PNG（自写编码器）；PPTX/DOCX 内嵌图片直接复制；题目与答案区域含图时裁图。
8. 围栏与注入检测：28 条中英文规则、NFKC 与零宽字符处理、跨行检测、围栏 id 由内容哈希生成、伪造围栏标记被移除；章节标题若可疑则替换为“第 N 章”。
9. 行为与 Skill v5.3 一致；原有接口改为带类型标注的纯函数和数据类。

## R2 证据与检索
1. 每章文本按约 600 字切成证据块，记录文件、页、所在章、在页文本中的字符区间。
2. BM25（k1=1.5，b=0.75），可按章过滤；查询无命中返回空。
3. 证据块有稳定 id，同一份资料重复导入 id 不变。

## R3 存储
1. SQLAlchemy 2（async）+ SQLite（WAL）；表：course、material、page、chapter、evidence、figure、question、job；所有表带 `tenant_id`（本地模式固定 `local`）。
2. 时间统一 UTC。
3. 同一数据目录下可有多门课程，互不影响。

## R4 增量导入
1. 扫描资料目录并计算每个文件的 sha256，与已有 material 比较：新增、变更、未变、删除。
2. 只重新解析新增和变更的文件；未变文件复用已存的页文本与图；删除的文件标记为 removed，其页与图不再参与。
3. 课程级结果（章节、证据、题目、题目裁图）每次导入按全部有效文件重建。
4. 没有任何文件变化时，第二次导入不解析任何文件。

## R5 并发与任务
1. 文件解析（文本 + 图区检测与渲染）在进程池中并行执行（pdfium 非线程安全）。
2. 任务表记录每个文件的解析任务：状态、尝试次数、租约到期时间、错误；单个文件失败不影响其他文件，失败信息写入导入报告。
3. 过期租约的任务可被重新领取；导入进程崩溃后再次导入能完成。
4. 导入过程产生结构化进度事件（开始、文件开始/完成/失败、阶段开始/完成、结束），供 CLI 显示，P3 直接转成 SSE。

## R6 命令行
1. `examprep ingest <资料目录> [--data-dir D] [--course 名称] [--lang zh|en] [--workers N] [--json]`：输出与 Skill setup 同类的报告（文件分类计数、章节列表与题数、题目数与有答案数、图数、扫描页、警告、注入告警页）。
2. `examprep search <课程> <查询>`：输出 BM25 命中的证据块（带文件与页）。

## 验收
- Skill 的 text、extract、chapters、questions、题号配对、figures、guard、index、判分测试迁移后全部通过。
- 内置中文样例：3 章、12 题、10 题有答案，章节标题、题目编号、题型、章节归属与 Skill 一致（golden 快照）。
- MIT 6.006 样例（`samples/fetch.py` 下载，不入库）：6 章、9 题、9 题有答案，章节标题、题目编号与章节归属、图数与题目裁图数与 Skill 一致；未下载时测试跳过并注明。
- 增量：第二次导入不解析文件；改一个文件只解析这一个；删一个文件后其题目消失。
- 导入耗时不高于 Skill（同机对比，记录数字）。
- `examprep` 包覆盖率 ≥ 85%；ruff、pyright 零错误；CI 全绿。
