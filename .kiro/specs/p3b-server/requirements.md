# P3b 本机服务端：需求

目标：给 P3c 的 Web 界面提供后端。2026-11-12 与用户确认：学习场景 80% 是一个人复习多门课，P3b 只做**本机单用户**——本地服务、事件推送、会话互斥、数据库迁移；鉴权留占位，不做多租户调度和排队背压（P6）。

## R1 启动

1. `examprep serve [--host 127.0.0.1] [--port 8765]` 启动服务，默认只监听本机回环地址。
2. 没配置模型也能启动：课程列表、导入、检索照常可用；学习接口返回 503 和配置说明。
3. 若 `examprep/web/` 下有构建好的前端（P3c），根路径返回前端；否则返回一个说明页。

## R2 本机安全

1. 只接受 Host 为回环地址（或 `--host` 指定的地址）的请求，防 DNS 重绑定。
2. 非 GET 请求带 Origin 时，Origin 必须是回环地址（任意端口，兼容 Vite 开发服务器）；否则 403。防止任意网站借浏览器调用本机服务（导入任意目录、花用户的 API 额度）。
3. 文件接口只能读课程数据目录和课程资料目录里的文件，拒绝路径穿越。
4. 接口不返回 API Key，只返回是否已配置。
5. 鉴权占位：所有接口经过同一个“当前用户”依赖，本机固定为 local / me，P6 换成真实鉴权。

## R3 课程与资料

1. 列出课程；课程详情（章节、题数、配图数、资料文件）。
2. 导入：给本机目录路径，SSE 推送导入事件（P2 的 IngestEvent），最后推送报告。路径不存在、不是目录返回 400；同一课程正在导入或正在讲课时返回 409。
3. 检索：`q`、`k`、`chapter`，返回文件、页码、片段。
4. 原文：某个资料文件某一页的文本和这一页上的证据块（P3c 阅读器跳转高亮用）；PDF 页面渲染成 PNG；配图、题目裁图图片。

## R4 学习

1. 打开一门课的学习会话，SSE 推送开场事件（进度、待答题、建议）。
2. 发一句话，SSE 推送这一轮的 StudyEvent（含流式 TutorDelta）。
3. 手动压缩、取消正在进行的一轮。
4. 查询状态（当前章、状态、是否在等作答、上下文用量与压缩阈值）。
5. 对话记录：学生原话和每轮事件（不含流式片段）写进会话事件，刷新页面后能取回最近 N 条。
6. 浏览器断开不打断这一轮：这一轮在后台跑完、照常落库，重新打开能看到结果。

## R5 会话互斥

1. 同一门课同一时间只有一轮在处理；处理中再发消息返回 409。
2. 跨进程互斥：命令行 `examprep study` 和服务端（或两个服务端）不能同时学同一门课。用数据库租约（选课记录上的 owner + 到期时间，原子更新），持有方定期续约，进程崩溃后租约过期自动释放。拿不到租约时，命令行提示并退出，服务端返回 423。
3. 服务端闲置 30 分钟的学习会话自动关闭并释放租约；服务关闭时释放全部租约。

## R6 数据库迁移

1. 用 Alembic 管理表结构，取代 `create_all`；迁移脚本随包发布，启动时自动升级到最新。
2. P3b 之前用 `create_all` 建的库：识别为初始版本后升级，数据不丢。
3. 测试：迁移后的表结构与模型定义一致。

## R7 质量

离线测试覆盖以上全部接口与互斥逻辑；总覆盖率不低于 85%；ruff、pyright 零错误；走 PR，CI 通过后合并。
